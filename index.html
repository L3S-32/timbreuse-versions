Télécharger pour Windows

Windows 10 et 11 · gratuit

Colle cette ligne dans CMD ou PowerShell, puis appuie sur Entrée : Timbreuse se télécharge et s’installe toute seule.

cmd /c "curl -L -o %TEMP%\Timbreuse-Setup.exe https://github.com/L3S-32/timbreuse-versions/releases/latest/download/Timbreuse-stable-Setup.exe && start %TEMP%\Timbreuse-Setup.exe"
